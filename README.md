# Proyecto Calculadora de Precios Multilenguaje

Este repositorio contiene la implementación de una calculadora de precios (IVA, Descuentos y Precio Final) desarrollada en tres lenguajes distintos para evaluar sus herramientas de documentación automática.

## Componentes del Proyecto
- **Python**: Implementado en `calculadora.py` (Documentado con Sphinx).
- **JavaScript**: Implementado en `calculadora.js` (Documentado con JSDoc).
- **PHP**: Implementado en `calculadora.php` (Documentado con phpDocumentor).

## Ver Documentación Técnica
Los manuales generados automáticamente se encuentran en las siguientes rutas dentro de la carpeta `docs/`:
- Ver JSDoc: `docs/jsdoc/index.html`
- Ver Sphinx: `docs/sphinx/_build/html/index.html`
- Ver phpDocumentor: `docs/phpdoc/index.html`
